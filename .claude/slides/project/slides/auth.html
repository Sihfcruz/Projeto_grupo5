SEGURANÇA

Fluxo de autenticação JWT

Access Token

Enviado no header Authorization: Bearer. Valida cada request protegido via middleware.

Expira em 15 min

Refresh Token

Armazenado no sessionStorage do browser. Renovação silenciosa interceptada em api.js.

Expira em 7 dias

1

Login

POST /auth/login → bcrypt compara senha, retorna access + refresh tokens.

2

Request autenticado

Middleware verifica JWT_SECRET (≥32 chars). Payload inclui id, nivel, idCargo.

3

Renovação automática

Ao receber 401, api.js chama POST /auth/refresh e reexecuta a request original.

✓

Startup validation

server.js verifica JWT_SECRET ≥32 chars e JWT_REFRESH_SECRET diferente antes de subir.
