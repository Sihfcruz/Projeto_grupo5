SOLUÇÃO

O que o Nômade entrega

Catálogo de Produtos

Hierarquia Marca → Categoria → Modelo → SKU (tamanho + cor + preço).

Estoque em Tempo Real

Movimentações atômicas via transação MySQL; view vw_estoque_atual para consulta consolidada.

Gestão de Vendas

Máquina de estados, múltiplas formas de pagamento, cálculo em centavos para precisão decimal.

Devoluções Seguras

Reembolso limitado ao valor pago; reposição automática de estoque na mesma transação.

Ajustes de Estoque

Entrada manual com motivo rastreável; toda alteração registrada com funcionário e timestamp.

Controle de Acesso

Níveis de cargo (nivelAcesso), autenticação JWT, soft-delete em todos os cadastros.
